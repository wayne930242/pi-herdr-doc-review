show_doc 組件庫

show_doc 開的每個 HTML 頁都會自動注入這套 kit，agent 只寫下面這些標籤，不寫 <style> 或 <script>。頁面自己寫的樣式永遠優先（kit 放在 CSS layer 裡）。每節上面是效果，下面是寫法。

這頁的表單是真的：按送出，答案會送回 agent。

基本樣式

不用任何 class：標題、段落、表格、程式碼、引言、details 都有預設樣式，並跟隨系統深淺色。

小標題

一般段落，inline code，連結。

pi-callout

提示框。tone 可用 note（預設，藍）、ok（綠）、warn（黃）、risk（紅）；title 可省略。

建議採用 Redis 快取。 測試全部通過。 需要重新部署。 正式區資料會被覆寫。 
<pi-callout title="結論">建議採用 Redis 快取。</pi-callout>
<pi-callout tone="ok" title="已驗證">測試全部通過。</pi-callout>
<pi-callout tone="warn" title="注意">需要重新部署。</pi-callout>
<pi-callout tone="risk" title="風險">正式區資料會被覆寫。</pi-callout>

pi-grid + pi-card

摘要卡片，自動排成響應式格線。卡片的 tone 決定頂端色條。

每秒 1,200 次 每秒 40 次 CPU 85% 
<pi-grid>
  <pi-card title="讀取量" tone="ok">每秒 1,200 次</pi-card>
  <pi-card title="寫入量">每秒 40 次</pi-card>
  <pi-card title="資料庫" tone="risk">CPU 85%</pi-card>
</pi-grid>

pi-badge

行內標籤，tone 同上。

狀態：已上線 待審 失敗 草稿

<p>狀態：<pi-badge tone="ok">已上線</pi-badge>
<pi-badge tone="warn">待審</pi-badge>
<pi-badge tone="risk">失敗</pi-badge>
<pi-badge>草稿</pi-badge></p>

pi-options + pi-option

方案並排比較。pros、cons 用分號分隔，自動變成 ＋／－ 清單；recommended 加上綠框和徽章，值是徽章文字。

讀多寫少，最適合。 保守做法。 
<pi-options>
  <pi-option title="Redis 快取" recommended="建議"
    pros="延遲降到 50 ms 內; 已有叢集" cons="要處理失效">
    讀多寫少，最適合。
  </pi-option>
  <pi-option title="讀取副本" pros="不用改程式" cons="成本加倍">
    保守做法。
  </pi-option>
</pi-options>

pi-form + pi-question + pi-choice

放在頁尾的決策表單，使用者按送出後，答案整理成一則訊息送回 agent。type 預設：有 pi-choice 是單選，沒有是文字題；multi 為複選。required 必填、hint 說明、other 加一個自填選項；pi-choice 可加 note 小字與 recommended 徽章。

Redis 快取 讀取副本 訂單 商品 
<pi-form title="請決定" submit="送給 agent">
  <pi-question name="strategy" label="採用哪個方案？" required>
    <pi-choice value="redis" recommended="建議" note="兩天可上線">Redis 快取</pi-choice>
    <pi-choice value="replica">讀取副本</pi-choice>
  </pi-question>
  <pi-question name="scope" label="先套用到哪些 API？" type="multi" other="其他">
    <pi-choice value="orders">訂單</pi-choice>
    <pi-choice value="products">商品</pi-choice>
  </pi-question>
  <pi-question name="notes" label="補充" hint="可留空"></pi-question>
</pi-form>
